# Contributing to TailorFolio

First off, thank you for considering contributing to TailorFolio! It's people like you that make the open-source community such a great place.

## 🌊 Drips.network Wave
This project is currently part of an active Drips Wave. Contributors can earn rewards by solving issues documented in our backlog.

### 📋 How to Pick Up an Issue
1.  **Browse Open Issues:** Head over to the [Issues tab](https://github.com/chigozirim007/resume-ai-platform/issues).
2.  **Request Assignment:** Comment on any open issue that isn't already assigned. A maintainer will assign it to you.
3.  **One at a Time:** To give everyone a chance, please only work on one issue at a time.

### 🛠️ Development Workflow
1.  **Fork the Repository:** Create your own copy of the repo.
2.  **Create a Branch:** `git checkout -b feature/issue-number-description`.
3.  **Setup Local Env:** Follow the instructions in the [README.md](README.md).
4.  **Make Changes:** Write clean, documented code.
5.  **Test Your Fix:** Ensure the app runs correctly and your changes work as expected.

### 🚀 Submitting a Pull Request
1.  **Link the Issue:** In your PR description, include `Closes #NUMBER`.
2.  **Provide Proof:** Include screenshots or a short screen recording of your changes in action.
3.  **Code Review:** A maintainer will review your code. Be prepared to make small adjustments if requested.

### ✅ Definition of Done
- Code is clean and follows the project's style.
- All technical requirements in the issue description are met.
- The PR is approved and merged by a maintainer.

Thank you for helping us build the future of AI-powered job seeking!
